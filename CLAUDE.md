# Мастерская сувениров 2.0 — памятка для Claude

Сайт msuvenirov.ru — мастерская печати в Калининграде (ТЦ «Экватор»). Владелец общается по-русски; отвечать по-русски, просто и без жаргона.

**Агентов (субагентов) и скилы НЕ запускать, если владелец прямо не попросил об этом в своём сообщении** — постоянное правило для всех чатов и сессий (01.11.2026, 06.11.2026). Разрешение на одну задачу не переносится на другие.

## Стек и команды
- Astro 5 (статика, `build.format: 'file'` → `/price.html`), Preact-острова: `src/components/islands/Calculator.tsx`, `OrderDialog.tsx`.
- `npm run dev` (порт 4321), `npm run build` (astro check + build в `dist/`), `npm test` (vitest, тесты цен).
- Сервер нужен Node ≥ 18.20.8 — поэтому Astro закреплён на 5.16.x, не обновлять до 6+ без проверки Node на сервере.

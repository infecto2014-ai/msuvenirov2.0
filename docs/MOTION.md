# Motion Design System — главная

**Версия 2 (14.11.2026).** Владелец: «анимации однотипные, дурацкие, сделай их меньше, более аккуратные с появлением
блоков и элементов, не прогрузкой снизу вверх». Пересобрано по скиллу `remove-animations` (Эмиль Ковальски):
каждую анимацию «судили», оставили только те, у которых есть назначение. Первая версия (GSAP: строки заголовков из
маски, шторки фото, параллакс, «магнит», качание шара) — в истории git, коммит a13ebb6.

## Принципы
1. **Меньше — лучше.** Движение только там, где оно помогает: первый экран один раз и мягкое появление блоков.
2. **Ничего не едет снизу вверх.** Только прозрачность (и лёгкое «оседание» главного фото на 3 %).
3. **Блок появляется целиком**, элементы внутри не «сыплются» по одному.
4. **Не мешать читать.** Блок начинает появляться чуть раньше, чем доходит до экрана; то, что видно при загрузке, не прячется.
5. **Отклик на нажатие** — короткое сжатие кнопки 0.97 (120 мс).
6. **«Уменьшить движение» в системе** — анимаций нет совсем.

## Что убрано и почему
- Строки заголовков «из маски» снизу вверх, выезд меток, подъём карточек и отзывов — однотипно, без назначения.
- Шторки на фото, «оседание» фото в каждой карточке — декоративно.
- Рост тёмных панелей при прокрутке, параллакс коллажа и фото «Компаниям», уход текста первого экрана — декоративно.
- «Магнитная» кнопка, следование фото за курсором — частые наведения, лишнее.
- Качание новогоднего шара — бесконечная анимация на постоянном элементе.
- Выезд шапки при загрузке — шапка видна на каждой странице.

## Техника
- CSS: конец `src/styles/lux.css` (ключевые кадры `lx-fade`, `lx-settle`, класс `.m-fade` / `.is-in`).
- JS: `src/scripts/home-motion.ts` — IntersectionObserver ставит `.is-in` блоку один раз. Без библиотек.
- `html.motion-ready` ставится в `<head>` до отрисовки, только без «уменьшить движение».

# Motion Design System — главная (14.11.2026)

Владелец: «нужны анимации… сначала разработай Motion Design System». Сделано по скиллам GSAP (официальные,
`.claude/skills/gsap-*`) и Emil Kowalski (`animate`, `choreograph`, `animation-performance`), плюс ui-ux-pro-max.
Код — `src/scripts/home-motion.ts` (GSAP 3.15.0 + ScrollTrigger + SplitText), CSS-часть — конец `src/styles/lux.css`.

## Принципы
1. **Движение = иерархия.** В каждой сцене один ведущий элемент (заголовок, фото), остальные — поддержка или стоят.
2. **Не анимируем всё подряд.** FAQ, меню, кнопки, таблицы, частые действия — без появлений (только мгновенный отклик).
3. **Только transform / opacity / clip-path.** Никаких width/height/top/left. Тяжёлые эффекты (параллакс, магнит) — только ПК.
4. **Ничего не блокирует клик.** Всё видимое сразу кликабельно; появления не задерживают кнопки.
5. **Один раз.** Появления при прокрутке проигрываются один раз (`once`), обратно не прячутся.
6. **Уважение к настройкам.** `prefers-reduced-motion: reduce` — анимаций нет, всё видно сразу.

## Длительность (токены `D`)
| Токен | Время | Где |
|---|---|---|
| micro | 120–160 мс | нажатие кнопки (CSS, scale 0.97) |
| ui | 200–240 мс | ховеры, цвета (CSS transitions) |
| reveal | 800 мс | появление карточек и текста |
| hero | 1100 мс | строки заголовка первого экрана |
| photo | 1600 мс | «оседание» фото (scale 1.14–1.2 → 1) |

## Кривые (токены `E`)
| Токен | Кривая | Когда |
|---|---|---|
| out | `expo.out` | всё, что появляется: быстрый старт, долгая мягкая посадка |
| text | `power4.out` | строки текста из маски |
| move | `power2.inOut` | то, что уже на экране и перемещается; шторка фото — `expo.inOut` |
| swing | `sine.inOut` | спокойное покачивание новогоднего шара |
| scroll | `none` + `scrub 0.5–0.8` | всё, что привязано к прокрутке |
`ease-in` на интерфейсе не используется никогда.

## Последовательность (хореография)
- Задержки **не равные**: `stagger { each: 0.08–0.11, ease: 'power1.in' }` — волна, а не очередь.
- Порядок — по важности: первый экран: шапка (0) → фото «оседает» и рамка раскрывается (0) → строки заголовка (0.18 с, шаг 0.11) → подзаголовок (0.5) → кнопки (0.6) → стеклянные карточки снизу (0.72).
- Заголовок раздела: метка выезжает слева (16 px) → строки h2 поднимаются из маски (шаг 0.09).
- Один вход на контейнер: если анимируется панель — её содержимое не «сыплется» отдельно (кроме фото-карточек).

## Поведение при прокрутке
- **Переход между секциями (фирменный ход):** тёмные скруглённые панели («Наши работы», «Компаниям», новогодняя) при входе вырастают из 94 % до 100 % (scrub).
- **Первый экран при уходе:** фото опускается медленнее страницы (глубина, +10 %), текст поднимается быстрее и бледнеет. Только ПК.
- **Глубина:** фото коллажа «Своя мастерская» и фото «Компаниям» плывут с разной скоростью (ПК).

## Фотографии
- **Каталог «Изделия»:** карточки появляются волной, фото внутри «оседает» (1.16 → 1). На ПК фото слегка следует за курсором (±7 px) и приближается (1.07) при наведении — `gsap.quickTo`.
- **Подарки к празднику, Наши работы:** шторка раскрывает фото снизу вверх (clip-path), фото оседает; после — CSS-ховер возвращается.

## Интерактивность
- Главная кнопка первого экрана — «магнит» (тянется к курсору на 5 px), только мышь.
- Нажатие любой кнопки — короткое сжатие 0.97 (CSS, 120 мс).
- Новогодний шар покачивается ±4° (3.2 с), только пока виден на экране.

## Технические правила
- Перед отрисовкой `html.motion-ready` прячет элементы первого экрана; GSAP их забирает (`html.motion-on`). Страховка: через 2,5 с без скрипта всё показывается.
- SplitText делит заголовки только после загрузки шрифта (не дольше 700 мс ожидания); у масок строк запас снизу под буквы у/р/д.
- После `load` — `ScrollTrigger.refresh()`.
- Вес: GSAP + плагины ≈ 50 КБ (gzip), только на главной.

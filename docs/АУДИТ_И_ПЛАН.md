# Мастерская сувениров (msuvenirov.ru): аудит и план переработки

Дата аудита: 31.10.2026. Исходный код: `neon-souvenir-studio/` (клон с GitHub).

---

## 1. Что сейчас из себя представляет сайт

- **Стек.** React 18 + Vite + Tailwind + shadcn, проект собран в Lovable. Есть самописный пререндер для SEO. Заявки уходят в Telegram через функции Supabase. Деплой: nginx и GitHub Actions.
- **Страницы.** Главная, `/pechat_na_tkani`, `/mug-print`, `/price` (973 строки кода), `/faq`, `/card` (визитка, закрыта от индексации), оферта, политика конфиденциальности.
- **Главная по порядку.** Hero, «О нас», витрина, «Что такое DTF», портфолио, «Почему мы», отзывы, логотипы клиентов, контакты.
- **Стиль.** Тёмный «неон»: свечение, пульсирующие кнопки, размытые пятна в каждой секции, капс. Выглядит как шаблон примерно 2021 года и мешает читать.
- **Аудитория.** На деле в основном частные клиенты: подарки, фанатский мерч. B2B заявлен только слоганом, отдельного предложения для компаний нет.

## 2. Ценообразование: что найдено

### Как устроены цены сейчас
| Категория | Модель цены |
|---|---|
| Кружки | Цена «всё включено» (кружка + печать) по ступеням тиража 1/10/30/100/200 |
| Текстиль | Изделие («от») + нанесение DTF по формату (А6–А3) и тиражу (1–4 / 5–10 / 20–50). Второй принт 70%, третий 50% |
| Значки, брелоки, магниты | Цена за штуку по ступеням 25/100/200/300/400/500 (магниты от 100) |
| Листовки | Формат × бумага × стороны × тираж |
| Визитки | Цена за штуку по тиражу 100/300/500, односторонние и двусторонние |
| Широкий формат | Цена за м², 3D-стикеры за см² (минимум 2000 ₽) |
| Календари | Свои сетки для каждого вида. Карманные считаются за весь тираж |

### Ошибки и противоречия (стоят денег и доверия)
- **Ни одного работающего калькулятора.** `FabricPrintCalculator.tsx` написан, но не подключён, и его цифры не совпадают с прайсом (DTF 300 ₽ против 800 ₽ в таблице).
- **Одни и те же товары стоят по-разному на разных страницах:**
  - футболка А4: 1550 ₽ в прайсе, 1650 ₽ в FAQ;
  - кружка «от»: 250, 450, 590 или 650 ₽ в зависимости от страницы;
  - подушка: 900 ₽ на главной, 1450 ₽ в прайсе;
  - визитки: «от 3 ₽» на главной, хотя минимум в прайсе 5,5 ₽.
- **Подозрительные ступени в таблицах:**
  - у хамелеона и глиттера цены от 10 до 200 шт совпадают до рубля;
  - «Стандарт МИНИ» за 100 шт дороже, чем за 50 (345 против 270 ₽);
  - карманные календари: 300 шт за штуку дороже, чем 200;
  - листовка А6 на плотной бумаге дешевле, чем на тонкой;
  - двусторонняя А6 стоит столько же, сколько односторонняя.
- **Дыры в тиражах.** Кружки 2–9 шт, DTF 11–19 и 50+ шт, значки меньше 25 шт.
- **Нет правил для:**
  - дизайна;
  - срочности: тексты противоречат друг другу («24 ч», «1 час», «без наценки»);
  - доставки;
  - минимальных тиражей.
- **Противоречивые факты о компании.** «С 2019 года» и «10+ лет опыта». «Четыре технологии» и «6 технологий».

**Главная возможность.** Ни у одного конкурента в Калининграде нет мгновенного калькулятора, сметы из нескольких позиций и КП в PDF. Это наше главное преимущество в новом сайте.

### Новая модель цен (предложение)
Все цены хранятся в одном файле `data/pricing.ts` числами. Из него питаются прайс, калькуляторы, цены «от» на карточках и микроразметка, поэтому расхождения исчезнут автоматически. Типы калькуляторов:

| Тип | Для чего | Как работает |
|---|---|---|
| Ступени тиража | Кружки, значки, брелоки, магниты, блокноты | Вид → тираж → цена за штуку и итог, подсказка «от N шт будет дешевле на X ₽» |
| Конструктор | Текстиль | Изделие и цвет → технология (с проверкой совместимости) → до 3 мест нанесения с форматом → тираж |
| Матрица | Листовки, визитки, календари | Формат × бумага × стороны × тираж |
| По площади | Широкий формат, стикеры | Размеры → м²/см² × тариф, с минимальной суммой |
| Готовые тиражи | Карманные календари | Выбор пакета |

Поверх всех калькуляторов:
- **Смета:** добавляем несколько позиций и отправляем одной заявкой.
- **Срочность:** отдельный переключатель тарифа.
- **Дизайн:** выбор из пакетов.
- **КП в PDF:** скачивание одним кликом.

## 4. Технические проблемы

- **Мобильная версия.** В шапке нет телефона и кнопки «Заказать», липкой панели действий нет. WhatsApp отсутствует.
- **Форма заявки:**
  - заявки не сохраняются в базу: если Telegram недоступен, заявка потеряна;
  - нет полей «изделие / тираж / формат»;
  - нет ограничений на размер файлов;
  - нет защиты от спама.
- **Мёртвый груз:**
  - около 35 неиспользуемых библиотек;
  - 52 дубля картинок (~2,2 МБ);
  - пустой service worker, при этом показывается баннер «установить приложение».
- **FAQ-разметка на главной** описывает FAQ, которого на странице нет. Это нарушение правил поисковиков.
- **Юридическое:**
  - иконка Instagram без пометки об экстремистской организации;
  - реквизитов ИП нет в футере.

## 5. Безопасность (исправить в первую очередь)

1. **Отзывы.** Правила базы позволяют любому вставить отзыв сразу «одобренным», в обход модерации.
2. **Telegram-вебхук модерации** не проверяет отправителя: любой может удалить опубликованный отзыв.
3. **Функция отправки заявок:**
   - нет лимитов на файлы;
   - нет защиты от спама;
   - нет экранирования HTML: имя со знаком `<` ломает отправку, и заявка теряется.
4. **Промокоды:** все активные коды можно прочитать напрямую из базы.
5. **nginx:** нет заголовков безопасности (HSTS, CSP и др.).
6. **`.env` в git.** Там только публичный ключ, это не утечка, но файл нужно убрать из репозитория.

## 6. SEO

### Что работает
Пререндер отдаёт полный HTML. Есть title, description и canonical. 301-редиректы настроены. 404 возвращает правильный код.

### Что ломает продвижение
1. **На странице /price в HTML нет ни одной цены.** Аккордеоны свёрнуты, и поисковик видит пустую страницу прайса. С /faq то же самое: ответы есть только в разметке.
2. **Страница /mug-print — сирота.** В меню она помечена «скоро», ссылок на услуги в статическом HTML нет.
3. **Каннибализация.** Главная и /pechat_na_tkani продвигаются по одному запросу. H1 главной — просто название бренда.
4. **Нет посадочных страниц** под визитки, календари, значки, магниты, наклейки, широкоформатную печать, корпоративные подарки и мерч. По этим запросам сайт не находится вообще.
5. **Микроразметка с ошибками:**
   - FAQ на главной без видимого контента;
   - LocalBusiness только на главной;
   - в OfferCatalog нет цен.

### Локальное SEO
- **Яндекс Бизнес:**
  - заполнить все рубрики;
  - добавить товары с ценами и фото;
  - регулярно публиковать новости;
  - отвечать на отзывы.
- **Яндекс Вебмастер:** привязать сайт к организации, указать регион, подключить IndexNow.
- **2ГИС и Google Business Profile:** завести и заполнить.
- **NAP (название, адрес, телефон):** везде в одном формате.

### Техническая основа нового сайта
- **Сборка:** статическая генерация, Astro с интерактивными блоками на React для калькуляторов и формы. Скрипта на страницах в разы меньше: быстрая загрузка и хорошие Core Web Vitals.
- **Тексты, цены и FAQ** всегда есть в HTML.
- **Sitemap и мета-теги** генерируются из одного конфига.
- **nginx:** http2, charset, правильное кэширование, заголовки безопасности.

# Стиль сайта «Ink» — стандарт (с 14.11.2026)

Владелец утвердил на главной и странице футболок, затем: «переработка всего сайта согласно нашим новым стандартам».
Сверено со скиллом ui-ux-pro-max (glassmorphism: blur 10–20 px, тонкая светлая рамка, контраст текста ≥ 4,5:1,
видимый фокус, reduced-motion; SVG-иконки, без эмодзи; зоны нажатия ≥ 44 px; мягкие анимации 300–400 мс).

## Где лежит
- `src/layouts/BaseLayout.astro` — тема включена на всех страницах (`theme="lux"` по умолчанию → `body.theme-lux`),
  подключает `src/styles/lux.css` (палитра, шапка, подвал, полосы, кнопки), `lux-calc.css` (калькулятор),
  `lux-tee.css` (CtaBand и общие блоки), `accent.css` (синие кнопки). `theme="plain"` — без темы (для служебных страниц).
- Образцы: `src/pages/index.astro`, `src/pages/pechat-na-futbolkah.astro`, компоненты `src/components/home/*`, `src/components/tee/*`.
- Анимации: `src/scripts/home-motion.ts` + docs/MOTION.md (подключён в BaseLayout).

## Цвета
- Чёрный `#000`, тёмно-синий `--navy #14213d`, светло-серый `#f2f2f2` / `#e5e5e5`, белый.
- **Акцент кнопок — синий кобальт `--coral: #2f5bea`** (наведение `--coral-dark: #2346c4`), белый текст.
  Используется только на главных кнопках и маленьких кружках-стрелках. Не красить им текст абзацев и фоны блоков.
- Жёлтый `#fca311` — только в отзывах (звёзды, кавычки). Никаких CMYK-цветов (голубой/розовый/жёлтый/красный) в оформлении,
  кроме образцов цвета изделий (свотчи) и фото.

## Полосы (фон разделов)
- Чередовать: белый (`<div class="band">`) / светло-серый (`band band-tint`) / тёмно-синяя скруглённая панель (`band band-ink`).
- Соседние полосы не должны совпадать. Без волн, без бумажной текстуры, без растровых точек и меток реза.

## Заголовки разделов
- Метка (eyebrow, разрядка) + h2 Rubik 700/800; акцентное слово — `<span class="serif">` (бледный тёмно-синий маркер
  на светлом, белый на тёмном).
- **Без номеров 01–04.** Вместо них значок в круге: `TeeHead` (`icon`, `eyebrow`, `id`, `title`, `mark`, `dark`)
  или `TshirtHead` (сам подбирает значок по метке). Класс `.sec-num` больше не использовать.

## Карточки и стекло
- Светлое стекло: `rgba(255,255,255,.78)` + `backdrop-filter: blur(14px)` + рамка `1px solid rgba(255,255,255,.9)` +
  тень `0 22px 44px -32px rgba(20,33,61,.4)`; скругление 20–32 px.
- На тёмно-синем: `rgba(255,255,255,.06)`, рамка `rgba(255,255,255,.14)`, белый текст, вторичный — `rgba(255,255,255,.72)`.
- Значки — SVG в круге: тёмно-синий круг на светлом, белый круг (тёмно-синяя иконка) на тёмном.
- Фото — ровные, скруглённые, без наклона. Без полароидов на кнопках, скотча, прищепок, вешалок, наклеек-стикеров,
  рукописных пометок (Caveat), полок.
- SVG-иллюстрации изделий (кружки, кепки, значки, стикеры, календари, шопперы, спецодежда, форма, листы) оставлять,
  но в тихой палитре: белый/серый/тёмно-синий, без цветных CMYK-кругов и точек вокруг.

## Кнопки
- Главная: синяя таблетка `--coral` с белым текстом и белым кружком со стрелкой (`Icon name="arrow"`), см. `.lx-btn-main`.
  Обычные `.btn-magenta` уже синие через тему.
- Второстепенная: светлое стекло с тонкой рамкой (на тёмном — прозрачная с белой рамкой).
- На тёмно-синем фоне главная кнопка тоже синяя кобальтовая (тема делает это сама).

## Анимации
- Только: один мягкий вход первого экрана, плавное проявление блоков (прозрачность, делает home-motion.ts),
  наведение (фон, сдвиг стрелки на 3 px), сжатие кнопки при нажатии. Никаких выездов снизу, качаний, параллакса.
  Всё отключается при `prefers-reduced-motion`.

## Телефон
- ≤760 и ≤560 px, без горизонтальной прокрутки на 390 px, зоны нажатия ≥ 44 px, шрифт не меньше 0,75rem.
- Ленты карточек — горизонтальная прокрутка со scroll-snap внутри блока.

## Не менять
- Цены — только из `src/data/pricing.ts`; тексты и факты — из data-файлов; не писать про вышивку и доставку.
- Логика калькулятора и заявок.

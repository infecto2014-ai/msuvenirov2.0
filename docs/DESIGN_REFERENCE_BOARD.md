# Доска визуальных референсов (категория A — только изучать)

Первое исследование — 12.11.2026. **Статус: черновик.** Сеть среды не пустила на сайты-галереи и сайты-примеры, поэтому ни один референс не просмотрен «глазами»: подтверждено только существование части адресов через поиск. Столбцы «что изучить» — гипотезы. Перед разработкой трёх концепций доску нужно пересобрать с просмотром сайтов и скриншотами (нужен доступ к галереям в настройках сети среды).

Правила (см. `COMPONENT_REUSE_POLICY.md`): изучаем композицию, типографику, иерархию, подачу товара, навигацию, анимации, сценарии. Не копируем сайт целиком, чужой фирменный стиль, тексты, фото, логотипы.

Ориентиры от владельца: креативные блоки, меньше квадратных элементов, без неона, спокойные тона, «премиум»; фирменная основа — CMYK 2.0 (бумага, полутона, метки реза, полароиды, пометки от руки).

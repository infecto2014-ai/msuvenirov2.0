# Чат на сайте и панель-приложение — инструкция

Посетитель пишет в чат на сайте → сообщение сохраняется **на вашем сервере** → вам приходит **уведомление** на телефон
и компьютер → вы отвечаете в **панели** `msuvenirov.ru/admin`, установленной как приложение. Telegram не используется.

Там же — заявки «Перезвоните мне», готовые ответы и переключатель «На связи / Не на связи».

- **Часть 1** — включить чат на сервере (один раз, после переезда на новый сервер).
- **Часть 2** — установить приложение на компьютер и телефон и включить уведомления.
- **Часть 3** — как пользоваться каждый день.

---

## Часть 1. Включаем чат на сервере (один раз)

Делается, когда новый сайт уже выложен на сервер в папку `/var/www/msuvenirov.ru`.
Команды выполняются на сервере: панель Timeweb Cloud → ваш сервер → **«Консоль»** (или через SSH).
Каждую команду копируйте целиком и нажимайте Enter.

### Шаг 1. Проверить Node.js

```bash
node -v
```

Должно быть `v18.20.8` или новее (лучше `v22…`). Если меньше или «command not found» — см. `docs/DEPLOY.md`, раздел 6.

### Шаг 2. Придумать пароль от панели

```bash
node /var/www/msuvenirov.ru/server/chat/setup.mjs
```

Программа попросит **придумать пароль** (не короче 8 символов) и **повторить** его. Символы при вводе не видны — так и задумано.
Она сама создаст файл настроек и ключи для уведомлений и напишет «Готово».

> Запомните пароль — с ним вы будете входить в панель на телефоне и компьютере.
> Забыли или хотите сменить — просто запустите эту же команду ещё раз и перезапустите чат (шаг 3, последняя команда).

### Шаг 3. Запустить программу чата

```bash
cp /var/www/msuvenirov.ru/deploy/chat/msuvenirov-chat.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now msuvenirov-chat
systemctl status msuvenirov-chat --no-pager
```

Должно быть зелёное **`active (running)`**. Проверка:

```bash
curl -s http://127.0.0.1:8787/api/health
```

Ответ: `{"ok":true}`. Чат теперь сам запускается при перезагрузке сервера и после каждого обновления сайта.

(После смены пароля: `systemctl restart msuvenirov-chat`.)

### Шаг 4. Обновить настройки nginx

Новый файл настроек сайта уже содержит адрес `/api/` для чата. Подробно — `docs/DEPLOY.md`, раздел 8
(там же — как вернуть старый файл, если что-то пойдёт не так). Коротко:

```bash
cp /var/www/msuvenirov.ru/deploy/nginx/msuvenirov.ru.conf /etc/nginx/sites-enabled/msuvenirov.ru
nginx -t && systemctl reload nginx
```

`nginx -t` должен написать `syntax is ok` и `test is successful`.
Проверка: откройте в браузере `https://msuvenirov.ru/api/health` — должно быть `{"ok":true}`.

Готово — дальше всё делается с телефона и компьютера.

## Часть 2. Устанавливаем приложение и включаем уведомления

Уведомления нужно включить **на каждом устройстве отдельно** (на компьютере и на телефоне).

### На компьютере (Windows, браузер Chrome или Edge)

1. Откройте `https://msuvenirov.ru/admin`, введите пароль.
2. Установите приложение:
   - **Chrome:** в адресной строке справа значок «Установить» (монитор со стрелкой) → «Установить»;
   - **Edge:** «…» → «Приложения» → «Установить этот сайт как приложение».
   Или нажмите в панели кнопку **«⬇ Установить приложение»**, если она появилась.
3. Ярлык «Чат МС» появится на рабочем столе и в меню «Пуск». Закрепите его на панели задач (правой кнопкой → «Закрепить»).
4. В приложении нажмите **«🔔 Включить уведомления на этом устройстве»** → **«Разрешить»**.
5. Проверьте: «Настройки» → **«Проверить уведомление»** — справа внизу должно появиться уведомление.

Если уведомления не приходят — проверьте в Windows: «Параметры» → «Система» → «Уведомления»: уведомления для Chrome/Edge
должны быть включены, режим «Не беспокоить» — выключен.

### На Android (Chrome)

1. Откройте `https://msuvenirov.ru/admin` в Chrome, войдите.
2. Меню «⋮» → **«Установить приложение»** (или «Добавить на главный экран»).
3. Откройте **«Чат МС»** с главного экрана.
4. Нажмите **«🔔 Включить уведомления на этом устройстве»** → «Разрешить».
5. «Настройки» → «Проверить уведомление».

### На iPhone (Safari, iOS 16.4 и новее)

На iPhone уведомления работают **только у приложения, добавленного на экран «Домой»**:

1. Откройте `https://msuvenirov.ru/admin` **в Safari**, войдите.
2. Кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → «Добавить».
3. Закройте Safari и откройте **«Чат МС» с экрана «Домой»**. Войдите ещё раз.
4. Нажмите **«🔔 Включить уведомления на этом устройстве»** → «Разрешить».
5. «Настройки» → «Проверить уведомление».

## Часть 3. Как пользоваться каждый день

### Что приходит в уведомлениях

| Уведомление | Что это |
|---|---|
| `💬 Чат №27` + текст сообщения | Посетитель написал в чат. Номер — у каждого посетителя свой |
| `💬 Чат №27 · +7 900…` | Тот же посетитель, он уже оставил контакт |
| `📞 Перезвоните: +7 (900) 111-22-33` | Заявка «Перезвоните мне» |

Нажмите на уведомление — приложение откроется сразу на этом чате или на списке звонков.
Если приложение уже открыто, новое сообщение сопровождается коротким звуком, а число непрочитанных видно на значке.

### Вкладка «Чаты»

- Слева (на телефоне — отдельным экраном) — все чаты, новые сверху. **Жирным** — непрочитанные, розовая цифра — сколько сообщений.
- **Зелёная точка** — посетитель сейчас на сайте. «печатает…» — пишет вам прямо сейчас.
- Под номером чата — страница, с которой пишут (например, `/pechat-na-kruzhkah`): сразу понятно, о чём вопрос.
- В открытом чате:
  - пишите ответ и нажмите ➤ (на компьютере — Enter; новая строка — Shift + Enter);
  - **⚡** — готовые ответы, вставляются одним нажатием;
  - **📎** — отправить картинку или файл (до 10 МБ): фото изделия, макет, счёт;
  - картинки посетителя видны прямо в переписке, файлы скачиваются нажатием.
- Сверху — контакт, если посетитель его оставил: телефон нажимается и звонит, Telegram открывается.
- Поиск над списком — по номеру чата, телефону и тексту.

Если посетитель ушёл с сайта — ваш ответ всё равно сохранится, и он увидит его, когда снова откроет сайт с того же устройства.
Если он оставил контакт — лучше написать или позвонить ему напрямую.

### Вкладка «Звонки»

Заявки «Перезвоните мне». Номер нажимается — сразу звонок. Отмечайте: **Новая → Позвонил → Готово**.
Новые подсвечены розовым, их число видно на вкладке.

### «На связи / Не на связи» (вверху справа)

- **Авто (10:00–20:00)** — посетители видят «На связи» в рабочее время и «ответим с 10:00» в остальное;
- **Всегда на связи** — например, если отвечаете вечером;
- **Не на связи** — если сегодня отвечать некому.

### Вкладка «Настройки»

- включить уведомления на этом устройстве и проверить их;
- **готовые ответы** — каждая строка отдельный ответ; поправьте под себя и нажмите «Сохранить»;
- «Выйти на этом устройстве».

## Если что-то не работает

| Что случилось | Что сделать |
|---|---|
| Панель пишет «Сервер чата недоступен» | На сервере: `systemctl status msuvenirov-chat --no-pager` — должно быть `active (running)`. Если нет: `systemctl restart msuvenirov-chat`. Журнал: `journalctl -u msuvenirov-chat -n 50 --no-pager` |
| «Неверный пароль», а пароль верный | Задайте новый: `node /var/www/msuvenirov.ru/server/chat/setup.mjs`, затем `systemctl restart msuvenirov-chat` |
| Уведомления не приходят | В панели «Настройки» → «Проверить уведомление». Если «Нет устройств…» — снова «Включить уведомления». На iPhone — только из приложения с экрана «Домой». В Windows — проверьте, что уведомления для браузера не выключены |
| «Уведомления запрещены в настройках браузера» | Разрешите их для сайта msuvenirov.ru: значок замка слева от адреса → «Уведомления» → «Разрешить» (на телефоне — в настройках приложения/сайта) |
| На сайте «Чат заработает после запуска…» | Сайт не достучался до программы чата — проверьте часть 1, шаги 3–4 |

Где хранятся данные: переписка — `/var/lib/msuvenirov-chat/chats` (файл на каждый чат), файлы — `/var/lib/msuvenirov-chat/files`,
звонки — `/var/lib/msuvenirov-chat/callbacks.json`. Всё на вашем сервере в России.

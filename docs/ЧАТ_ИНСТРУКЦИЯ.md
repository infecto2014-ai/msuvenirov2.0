# Чат на сайте — инструкция

Сообщения из чата на сайте и заявки «Перезвоните мне» приходят **только вам лично** в Telegram, от отдельного бота.
Вы отвечаете прямо в Telegram — ответ появляется у посетителя в окне чата на сайте.

Всего три части:

- **Часть 1** — создать бота в Telegram. Это делаете вы, около 10 минут, нужен только телефон.
- **Часть 2** — включить чат на сервере. Один раз, когда будет новый сервер; можно делать вместе со мной.
- **Часть 3** — как пользоваться каждый день.

---

## Часть 1. Создаём бота (10 минут, с телефона)

### Шаг 1. Создать бота

1. Откройте Telegram, в поиске найдите **@BotFather**. У настоящего синяя галочка.
2. Нажмите **«Запустить»** (или напишите `/start`).
3. Напишите `/newbot`.
4. BotFather спросит **имя** бота — его вы будете видеть в списке чатов. Напишите, например:
   `Мастерская сувениров — чат сайта`
5. Потом он спросит **адрес** бота (username). Он должен быть на латинице и заканчиваться на `bot`, например:
   `msuvenirov_chat_bot`
   Если адрес занят, придумайте другой: `msuvenirov39_chat_bot`, `msuv_site_chat_bot` и т. п.
6. BotFather пришлёт сообщение «Done! Congratulations…». В нём строка вида
   `1234567890:AAH...длинный_набор_символов`
   Это **токен** — пароль от бота.

> ⚠️ **Токен — как пароль.** Никому его не пересылайте, не публикуйте и не вставляйте в чаты.
> Он понадобится один раз — при настройке сервера (часть 2). Если токен случайно попал не туда —
> в @BotFather: `/revoke` → выбрать бота → получите новый токен, старый перестанет работать.

### Шаг 2. Нажать «Запустить» у своего бота

Это **обязательно**: пока вы не нажали «Запустить», бот не может вам писать.

1. В том же сообщении от BotFather есть ссылка на бота: `t.me/msuvenirov_chat_bot` — нажмите на неё.
2. Нажмите **«Запустить»** (Start). Бот пока ничего не ответит — это нормально, он заработает после части 2.

### Шаг 3. Узнать свой ID в Telegram

Бот должен знать, кому отправлять сообщения, — для этого нужен ваш ID (число).

1. В поиске найдите **@userinfobot** и нажмите **«Запустить»**.
2. Он сразу пришлёт: `Id: 123456789` — это ваш ID. Запишите число.

### Шаг 4 (по желанию). Сделать бота красивым

В @BotFather:
- `/setuserpic` → выбрать бота → отправить картинку (например, логотип мастерской);
- `/setdescription` → выбрать бота → например: «Сообщения из чата на сайте msuvenirov.ru».

### Что подготовить к части 2

- токен бота (из шага 1);
- ваш ID (из шага 3).

**Не отправляйте их в чат.** Вы введёте их сами в конце настройки — на сервере, в одном файле
(в части 2 показано, где именно).

## Часть 2. Включаем чат на сервере (один раз)

Делается после переезда на новый сервер с 2 ГБ памяти, когда новый сайт уже выложен в
`/var/www/msuvenirov.ru`. Команды выполняются на сервере: в панели Timeweb Cloud → ваш сервер →
**«Консоль»**, или через SSH. Каждую команду копируйте целиком и нажимайте Enter.

### Шаг 1. Проверить Node.js

```bash
node -v
```

Должно быть `v18.20.8` или новее (лучше `v22…`). Если меньше или «command not found» — см. раздел 6 в `docs/DEPLOY.md`.

### Шаг 2. Записать токен и ID на сервер

```bash
cp /var/www/msuvenirov.ru/deploy/chat/msuvenirov-chat.env.example /etc/msuvenirov-chat.env
nano /etc/msuvenirov-chat.env
```

Откроется текстовый файл. Заполните три строки (после знака `=`, без пробелов и кавычек):

```
TG_BOT_TOKEN=1234567890:AAH...ваш_токен
TG_CHAT_ID=123456789
TG_WEBHOOK_SECRET=придумайте_длинное_слово_латиницей_например_msuv_chat_2026_x7k
```

- `TG_BOT_TOKEN` — токен из части 1, шаг 1;
- `TG_CHAT_ID` — ваш ID из части 1, шаг 3;
- `TG_WEBHOOK_SECRET` — любой набор латинских букв, цифр, `_` и `-` (это «пароль» между Telegram и сервером,
  запоминать не нужно, но он понадобится в шаге 5 — скопируйте его).

Сохранить и выйти: **Ctrl + O**, **Enter**, затем **Ctrl + X**.

Закрыть файл от чужих глаз:

```bash
chmod 600 /etc/msuvenirov-chat.env
```

### Шаг 3. Запустить программу чата

```bash
cp /var/www/msuvenirov.ru/deploy/chat/msuvenirov-chat.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now msuvenirov-chat
systemctl status msuvenirov-chat --no-pager
```

В ответе должно быть зелёное **`active (running)`**. Проверка:

```bash
curl -s http://127.0.0.1:8787/api/health
```

Ответ: `{"ok":true}`.

Программа теперь запускается сама при перезагрузке сервера и после каждого обновления сайта.

### Шаг 4. Обновить настройки nginx

Новый файл настроек сайта уже содержит адрес `/api/` для чата. Как его применить — `docs/DEPLOY.md`, раздел 8
(там же — как вернуть старый, если что-то пойдёт не так). Коротко:

```bash
cp /var/www/msuvenirov.ru/deploy/nginx/msuvenirov.ru.conf /etc/nginx/sites-enabled/msuvenirov.ru
nginx -t && systemctl reload nginx
```

`nginx -t` должен написать `syntax is ok` и `test is successful`.
Проверка снаружи: откройте в браузере `https://msuvenirov.ru/api/health` — должно быть `{"ok":true}`.

### Шаг 5. Связать бота с сайтом

Подставьте **свой токен** и **свой TG_WEBHOOK_SECRET** из шага 2 (угловые скобки убрать):

```bash
curl -sS "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
  -d "url=https://msuvenirov.ru/api/tg/webhook" \
  -d "secret_token=<TG_WEBHOOK_SECRET>" \
  -d 'allowed_updates=["message"]'
```

Ответ: `{"ok":true,"result":true,"description":"Webhook was set"}`.

### Шаг 6. Проверка

1. Откройте сайт с телефона или компьютера (лучше в другом браузере или в режиме инкогнито — как обычный посетитель).
2. Нажмите **«Чат»**, напишите «Проверка».
3. В Telegram от вашего бота придёт: `💬 Чат №1 · /…  Проверка`.
4. Нажмите на это сообщение → **«Ответить»** → напишите «Ответ работает» → отправьте.
5. На вашем ответе появится 👍, а на сайте в окне чата — «Ответ работает».
6. Нажмите в чате **«Перезвоните мне»**, введите номер — в Telegram придёт `📞 Перезвоните: …`.

Если всё пришло — чат работает. После проверки можно отключать подписку Jivo.

## Часть 3. Как пользоваться каждый день

### Какие сообщения приходят

| Сообщение от бота | Что это |
|---|---|
| `💬 Чат №27 · /pechat-na-kruzhkah` + текст | Посетитель написал в чат. Номер чата — у каждого посетителя свой; после `·` — страница, с которой он пишет |
| `📇 Чат №27: оставили контакт — +7…` | Посетитель оставил телефон или Telegram — сможете связаться, даже если он ушёл с сайта |
| `📞 Перезвоните: +7 (900) 111-22-33 · Анна` | Заявка «Перезвоните мне» — нужно позвонить |

### Как ответить

1. **Нажмите на сообщение посетителя** (на телефоне — удержите палец; на компьютере — правой кнопкой) → **«Ответить»**.
2. Напишите ответ и отправьте.
3. Появилась **👍** на вашем сообщении — ответ ушёл посетителю.

Важно:
- **Отвечайте именно через «Ответить».** Если просто написать боту, он не поймёт, кому это, и подскажет:
  «Нажмите „Ответить“ на его сообщении».
- **Можно отвечать на любое сообщение этого чата** — на первое, на последнее или на свой предыдущий ответ.
  По номеру «Чат №27» удобно понимать, что это один и тот же человек.
- **Отвечайте текстом.** Картинки и файлы в чат пока не передаются — бот об этом напомнит.
  Если нужно отправить макет или фото — попросите контакт и пришлите в мессенджер.

### Если посетитель уже ушёл с сайта

- Ваш ответ всё равно сохранится — посетитель увидит его, когда снова откроет сайт с того же устройства.
- Если он оставил контакт (`📇`) — лучше написать или позвонить ему напрямую.

### Советы

- Закрепите бота в списке чатов Telegram и не выключайте для него уведомления.
- В нерабочее время чат сам пишет посетителю «Сейчас не на связи — ответим с 10:00», так что отвечать сразу не обязательно.

## Если что-то не работает

| Что случилось | Что сделать |
|---|---|
| Сообщения с сайта не приходят | На сервере: `systemctl status msuvenirov-chat --no-pager` — должно быть `active (running)`. Если нет: `systemctl restart msuvenirov-chat`. Журнал ошибок: `journalctl -u msuvenirov-chat -n 50 --no-pager` |
| Пришло, но ответ не доходит (нет 👍) | Проверьте связь бота с сайтом: `curl -s "https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo"` — в ответе должен быть `"url":"https://msuvenirov.ru/api/tg/webhook"` и не должно быть `last_error_message`. Если не так — повторите часть 2, шаг 5 |
| Бот вообще молчит | Убедитесь, что нажимали «Запустить» у бота (часть 1, шаг 2) и что `TG_CHAT_ID` — ваш ID из @userinfobot |
| Поменяли токен (`/revoke`) | Впишите новый токен: `nano /etc/msuvenirov-chat.env` → сохранить → `systemctl restart msuvenirov-chat` → повторите часть 2, шаг 5 с новым токеном |
| На сайте «Чат заработает после запуска…» | Сайт не достучался до программы чата — проверьте часть 2, шаги 3–4 (`https://msuvenirov.ru/api/health` должен отвечать `{"ok":true}`) |

Переписка хранится на сервере в папке `/var/lib/msuvenirov-chat` (по файлу на каждый чат),
заявки «Перезвоните мне» — в `/var/lib/msuvenirov-chat/callbacks.jsonl`.
